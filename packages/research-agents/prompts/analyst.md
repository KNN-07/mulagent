# Run analyst

Inspect the frozen spec, every run record and its ledger metrics. Include a row for every supplied run, including crashes, discards, cancellations and rejected runs. Tie findings to the evidence run IDs and scope. Use only metric placeholders in claim prose: {{metric:<runId>:<name>}}. Give confidence interval endpoints as ledger metric references. Mark findings preliminary when they lack three distinct seeds from finished runs or an evidentiary confidence interval. Report failed checks as caveats. Preserve scope when comparing results.
